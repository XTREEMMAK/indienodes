# Test assets

Small, project-authored files the end-to-end tests need. Unlike `testing/fixtures/`
and `testing/sites/`, **these are committed**, and the distinction matters:

- Those two directories are gitignored because they embed real, identifying
  third-party content that has no reason to sit in a public repo. See
  `testing/README.md`.
- Everything here is generated by this project, contains nobody's work, and is
  therefore safe to commit — which is the whole point, because a test that reads
  a gitignored file passes only on the machine that generated it.

That is not hypothetical: three ambient and mini-player tests read a track from
`testing/sites/` and so passed locally while failing on every clean checkout. CI's
first runs caught it.

## `test-tone.wav`

15 seconds of a quiet 220 Hz sine, 8 kHz mono 8-bit PCM (~120 KB). Deliberately a
real, decodable signal rather than silence: several tests assert that playback
actually started (`paused === false`), and some drive the audio-reactive
background, which needs something to analyse.

Regenerate with:

```python
import math, wave
RATE, SECONDS = 8000, 15
with wave.open('testing/assets/test-tone.wav', 'wb') as w:
    w.setnchannels(1); w.setsampwidth(1); w.setframerate(RATE)
    w.writeframes(bytes(
        max(0, min(255, 128 + int(40 * math.sin(2 * math.pi * 220 * i / RATE))))
        for i in range(RATE * SECONDS)
    ))
```
